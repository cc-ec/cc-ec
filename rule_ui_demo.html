Dispatch Rule Engine - Tags

Logic: Rules assign tags based on order attributes. Use 'Any' if a condition should match all values for that attribute. Rules are processed by Sequence Level (lowest number first). All rules within a level are checked against the order. If any rule matches in a level, required tags from all matching rules in that level are determined. Processing behaviour depends on the level's 'Stop' setting: if checked, processing stops; if unchecked, processing continues to the next level, accumulating tags. If no rules match in a level, processing always continues. Drag rules between levels to change their sequence.
